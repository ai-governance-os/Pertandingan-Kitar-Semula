📱 这是什么？

环保小兵是一个学校用的网站，做三件事：

  1. 🏆 回收比赛 — 两队竞争，谁回收得多谁赢
  2. ⭐ 学生星星奖励 — 不只奖环保，也奖学业 + 品格
  3. 🤖 AI 助手 — 拍照让 AI 教你这垃圾怎么分类
老师 / 家长 / 学生都能用，但只有老师能输入数据。

🚀 第一次打开

老师/家长/学生都用同一个网址打开 App（手机或电脑都可）：

https://你的网址.vercel.app

打开后第一眼看到「📊 战况」页面 —— 显示哪一队回收比较多。

📸 建议截图位置：战况页面（含比赛排名）

👥 两种使用者

谁看什么能做什么
👨‍👩‍👧 家长 / 学生战况 + 奖品只能看，不能改
👨‍🏫 老师（登入后）全部 5 页可以输入、给星、记录

🔓 老师怎么登入？

  1. 网页右上角点 🔓 老师登入
  2. 输入你自己的老师账号 ID 和密码（每位老师一组，向 Admin 索取）
  3. 点 「登入 · Log Masuk」

✅ 登入成功后，多出 3 个按钮：📝 记录 / 🤖 AI / ⚙️ 管理

⭐ 每次加星/扣星都会记下是哪个账号操作的。只有 Admin 账号登入后能在「⚙️ 管理」看到全部老师的记录并撤销。
📸 建议截图位置：登入框 + 登入前后模式栏对比

🗂️ 五个功能按钮（详细说明）

1️⃣ 📊 战况 · Status（所有人可看）

用途：投影在课室或电视上，给学生 / 家长看比赛进度。

看到什么：

  • 🦁 云狮组 vs 🐲 飞龙组 的总分排名
  • 每组回收了多少 kg
  • 每组值多少 RM
📸 建议截图：战况大屏幕（含两队头像 + 分数）

2️⃣ 🎁 奖品 · Rewards（所有人可看，老师可改）

重点页面。每个学生累积多少 ⭐ 一目了然。

公开看到：

  • 🏆 学生星星排行榜（按⭐余额排序）
  • 🎁 可换奖品列表（每个礼物多少 ⭐、库存多少）

老师额外看到（登入后）：

  • 每个学生旁边 [+] [−] [🎁] 三个按钮
  • 折叠的「🛠️ 管理奖品」（增/删/调库存）

怎么用：

👉 给学生加 ⭐：

  1. 找到学生，点 [+]
  2. 选星型（环保 / 学业 / 品格 / 助人...）
  3. 输入数量（默认 1）
  4. 写原因（可选）
  5. 点 + 加 1 ⭐ ✅

👉 扣 ⭐（同样流程，但原因必填）：

  1. 点 [−] → 选 ⚠️ 扣星
  2. 必须写原因（避免乱扣）

👉 学生用 ⭐ 换礼物：

  1. 找到学生，点 [🎁]
  2. 弹出可换礼物（星星不够的会变灰）
  3. 点礼物图标 → 自动扣⭐ + 减库存
📸 建议截图：排行榜 + 加星 modal（含 🌱环保/📚学业 两组按钮）

2️⃣.5 🐾 宠物园 · Eco Pets（所有人可看）

给学生看的页面。每个学生有一只自己的神兽，做环保拿星星，神兽就会长大。
全校 19 人 19 只，没有两个人拿到同一只。

规则（很重要，要跟学生讲清楚）

  • 🍽️ 宠物自动吃你赚到的星星 —— 不用点「喂食」，拿到星星就等于喂了
  • 🎁 换礼物不会让宠物变小 —— 花掉的星星只是买东西，宠物记得你「总共赚过多少」
  • 🥚 5 个进化阶段：蛋 → 幼体 → 少年 → 成年 → 传说（累计 0 / 25 / 70 / 150 / 300 星）
  • 🐉 19 只神兽各不相同：麒麟、凤凰、九尾狐、应龙、白泽、灵龟、星鹿、云豹、海麟、貔貅、雷鸟、竹灵、朱雀、玄武、白虎、青龙、狮鹫、雪貂灵、火鼠。神兽只会越变越华丽，不会变成另一种生物
  • 😟 太久没有新星星，宠物会饿：3 天有点饿、7 天饿、14 天以上很饿
  • ⚠️ 饿超过 14 天，宠物外表会退回上一阶段 —— 但成长值没有减少，一拿到新星星马上变回来

老师能做的

点任何一只宠物 → 详情框底下有：

  • 🔄 换宠物 —— 帮学生换一只（19 只可选）。换走的那只会被锁住，别的学生不会再分到
  • ✏️ 改名字 —— 给神兽取名
💡 学生不需要登入，直接打开网址就看得到全班的神兽。
乐园是 3D 的：手指拖动可以看四周，放手几秒后镜头自己回到原来的角度；点任何一只看它的详情。
手机太旧跑不动 3D 的话，会自动换成 📋 列表版，不会卡死。适合投影在课室或走廊电视上。

3️⃣ 📝 记录 · Input（老师专用）

用途：比赛日称重，输入每组每种回收物的 kg。

怎么用：

  1. 选 Session（比如「第一次」）
  2. 选组别（🦁 云狮组 / 🐲 飞龙组）
  3. 每种回收物输入 kg 数字：
  4. 🥫 铝罐 (RM 5.50/kg) — 最值钱
  5. 🛢️ 回锅油 (RM 3.40/kg)
  6. 📰 报纸 (RM 1.00/kg)
  7. 🔩 铁制品 (RM 0.40/kg)
  8. 📦 纸皮 / 🧴 塑料 (RM 0.25/kg)
  9. 📄 纸张 (RM 0.10/kg)
  10. 系统自动算分 = kg × 每 kg 价格 × 100
📸 建议截图：记录页面（每类一行 input）

4️⃣ 🤖 AI · 智能分析（老师专用）

重点功能！ 教学时刻：「这个垃圾怎么分？」让 AI 给标准答案。

怎么用：

  1. 点 🤖 AI
  2. （可选）选个学生
  3. 点 📸 拍照 或 🖼️ 上传
  4. 等 5-15 秒
  5. 看 AI 分析结果（彩色卡片）
  6. 给学生奖 ⭐（如果识别正确）

AI 会告诉你什么？

例子：扫一个 Tetra Pak 牛奶盒

✅ 可回收 · Recyclable               92%
建议：拧下塑料盖丢塑料桶，盒身倒空冲洗
     压扁丢纸桶。

材料：纸板 + 塑料盖 + 内层铝膜

拆解步骤：
┌──────────────────────────────────┐
│ 1. 蓝色塑料盖                     │
│ → 投放 塑料桶                     │
│ 📝 拧下来 · Unscrew the cap       │
├──────────────────────────────────┤
│ 2. 纸盒身                         │
│ → 投放 纸张桶                     │
│ 📝 倒空 → 冲洗 → 撕开摊平         │
├──────────────────────────────────┤
│ 3. 内层铝箔                       │
│ → 投放 纸张桶（与盒身一起）        │
│ 📝 不用单独撕                     │
└──────────────────────────────────┘

💬 给学生：做得好！拧盖 → 倒空 → 压扁，三步！
🧑‍🏫 老师备注：示范拧盖动作

AI 能识别什么？

✅ 强项：

  • 常见回收物（铝罐、塑料瓶、纸盒、报纸等）
  • 混合材料（教 AI 拆解 Tetra Pak、奶粉罐、牙膏管）
  • 危险物（电池、喷雾罐、灯管 → 给安全提醒）
  • 学生堆在一起的杂物（一袋多件 → 逐件分析）

⚠️ 弱项：

  • 模糊照片（光线暗、太远）→ AI 会说「需要老师确认」
  • 太多东西堆一起（>8 件）→ 会漏小件
  • 罕见 / 怪异物品 → 偶尔答错（老师覆盖即可）

💡 给老师的小建议：

  • 🌟 一次拍一件最准（教学时刻最好）
  • 🌟 背景干净（白色桌面 > 杂乱地板）
  • 🌟 拍清楚标签 / 盖子（AI 看得清才拆得好）
  • 🌟 AI 答错也没关系 —— 老师自己加 / 改星就好

5️⃣ ⚙️ 管理 · Admin（老师专用）

用途：调比赛设置、导出数据、重置赛季。

可以做：

  • 新增 / 删除 Session（「第一次」「第二次」...）
  • 调整每种回收物的 RM/kg 价格
  • 看哪些学生没带回收物（累计几次会被列为「不可领奖」，由 Admin 自己设定，预设 3 次）
  • 调红名单门槛 —— Admin 账号登入后，在「组员名单与年终资格」上方用 [−] 3 [+] 调整。改了立刻重算所有学生（会先跳出确认框告诉你几个人受影响）
  • 导出 CSV —— 给校长 / 家长报告用
  • 重置赛季 —— 新学年清零（小心！）
📸 建议截图：管理页（含 session 列表 + 导出按钮）

🤖 什么是 API？为什么 AI 要花钱？

简单解释

API = AI 公司提供的「外卖服务」

你的网站 ──「这张照片是什么？」──→ OpenAI 公司
你的网站 ←──「是 Tetra Pak，3 步处理」── OpenAI 公司

每次「叫外卖」要付钱（几仙美金）。

我们用的 AI 叫 GPT-4o，是 OpenAI 公司的产品。
每次「拍照分析」，OpenAI 收我们一点点钱（几美仙）。

钱怎么算？

一次扫描单价例子
简单物（一个铝罐）约 USD $0.0125 仙马币
复杂物（Tetra Pak 含 3 part）约 USD $0.0167 仙马币
一堆杂物约 USD $0.0209 仙马币

USD $5（约 RM 23）能扫多少次？

最少 300 次，正常 400-500 次。
学校用法月扫描次数$5 撑多久
偶尔 demo / 节日活动20 次1 年半
每周一次比赛 + 教学60 次5-6 个月
每天教学示范（狠用）200 次1.5 个月

➡️ 充值 USD$10 = 一整学年绰绰有余

钱给谁？

学校 → 充值 USD$5 给 OpenAI 公司 (信用卡)
       ↓
       钱进 OpenAI 账户
       ↓
学生每次拍照 → 自动从余额扣款
       ↓
没钱了 → AI 停止工作（学校自己再充值）

➡️ 钱不会被偷（钥匙锁在 Supabase 服务器，外人看不到）
➡️ 钱用完就停（不会乱扣额外费用，可以设月度上限）

❓ 常见问题

Q: 我不是 IT 老师，能用吗？

A: 完全能。这个 App 不需要装东西。手机浏览器打开网址就可以。

Q: 学生可以自己拍照分析吗？

A: 不行。只有老师登入后才能用 AI（防止学生玩耍烧钱）。

Q: 网络断了能用吗？

A: 记录 / 看战况 / 给星星 → 可以（数据存在浏览器）。
AI 扫描 → 不行（要联网才能问 OpenAI）。

Q: 数据会丢吗？

A: 不会。3 重保护：

  1. 浏览器 localStorage（自动存）
  2. Supabase 云端（自动同步）
  3. 手动导出 CSV（管理页一键导出）

Q: 老师密码可以改吗？

A: 可以。让 IT 协调员编辑 app.jsx 里的 ADMIN_PW（一行字）。

Q: AI 答错怎么办？

A: 老师有最终决定权。AI 只是辅助，老师可以覆盖、改原因、调星星。

Q: 一个手机多个老师轮流用？

A: 可以，但要自己登出登入。一台设备登入后，30 天免密。

Q: 家长可以看到自己孩子的星星吗？

A: 可以。家长直接打开网址 → 点 🎁 奖品 → 看排行榜里孩子的⭐。
不用登入，也看不到能改的按钮。

🆘 出问题了求救

现象处理
页面空白 / 转圈强制刷新：手机长按刷新；电脑 Ctrl+Shift+R
「AI 未启用」红框找 IT 协调员检查 Supabase 部署
「OPENAI_API_KEY」错误API 余额用完了，需要充值
AI 一直转圈不动网速太慢，等 30 秒；不行就重拍
星星数字不对进 ⚙️ 管理 看星星账本，可以撤销
想清空所有数据⚙️ 管理 → 重置赛季（会清空 weight 数据，星星保留）
