# Legendary beetle animation pilot

Generated with the built-in ImageGen tool on 2026-09-12, using the existing
`assets/pet-park/evolution/hornbeetle/5.webp` as identity/style reference.

Selected asset: `legend-keyframes-v1.png`. Sixteen distinct poses, four columns.
The image is RGB on white, **not transparent**. It is only used in the separate
white interaction studio, not as a replacement for park sprites. Original static
evolution art is preserved. No student data or unlock rules were changed.

Prompt specification: preserve the friendly emerald/gold legendary rhinoceros
beetle, cream face, amber eyes, branching golden horn, gem chest armour and
iridescent wings. Same three-quarter camera and scale, a 4x4 sheet. Sequence:
calm, smiling, crouching, opening wings, raised wings, downstroke, upstroke,
downstroke, raised claw, outward wave, inward wave, returning claw, landing
preparation, landing crouch, straightening, calm. No text or environment.

Transparency generation and a targeted alpha extraction attempt both produced
baked checkerboards and were rejected. Final edit prompt: change only the
checkerboard to uniform pure white RGB 255,255,255; preserve all sixteen poses,
positions and character shapes; no texture, shadow, border or lettering.

Known quality limits: AI keyframes are not hand-cleaned in-betweens or a skeleton;
pose volumes and horns vary slightly. Three short choreographies share these
sixteen poses. Full six-stage/all-species production animation and recorded
Chinese character voices remain unfinished. Do not label this production-ready.
