# 神兽库与六阶成长设计

50 种原创神兽，19 位在籍学生各有不同伙伴，不含乌龟。借鉴收集养成游戏清楚可辨的进化层级，造型为原创，不使用 Pokémon 或 Digimon 的现有角色。

## 李冠德 · 天角仙

沿用名册准确姓名：Lucas Lee Guan Teck 李冠德，飞龙组。首次升级自动配置天角仙；之后以 ADMIN 的选择为准，不会每次刷新重置。其余 18 位学生保留原有神兽分配。

|---|---|---|---|
| 0 | 蛋 | 翡翠甲纹蛋 | 角纹叩蛋 |

## 使用

- ADMIN：管理 → 学生名册 → 选神兽；也可从学生成长图鉴进入神兽库。
- 看图搜索、按虫灵／海灵／飞羽／灵兽筛选，预览六阶造型及约 3 秒表演。
- 选择已有人拥有的品种时明确提示交换对象，二次确认后才交换。保留姓名、组别、昵称和奖励记录。
- 学生可预览自己的未来形态与招式；明确标注尚未解锁及还差多少张奖励卡。
- 成长沿用现有本月奖励卡规则，兑换奖品不扣成长值；预览不发卡、不修改成长。

## 素材与实现

使用内置 ImageGen 生成 50 张六阶原画，再进行本地逐格抠图和 WebP 压缩。最终游戏素材位于 [assets/pet-park/evolution](../assets/pet-park/evolution/)：50 个品种目录，每个包含 0.webp 至 5.webp，共 300 张独立透明造型。

生成提示词完整保存于 [原有 19 种提示词](evolution-prompts-20260909.json)、[新增 31 种提示词](expanded-library-prompts-20260909.json)及[传奇边缘修复提示词](legendary-repair-prompts-20260909.json)。未使用 API/CLI 图像生成。

[天角仙六阶展示](hornbeetle-evolution.png) · [50 种传奇图鉴](beast-library-50.png)

互动采用按需运行的 2D 网格形变、独立移动轨迹、头部／翼尖／尾部动作和阶段道具效果；并非完整 3D 骨骼动画。图鉴内约 3 秒大动作；乐园中的蛋／破壳约 3.4 秒弹跳，幼兽至传奇约 6.4 秒绕园巡游，完成后回到原位。只有被点中的神兽运行表演，其余使用静态压缩图，降低手机负担。

巡游使用可见乐园坐标，避开顶部控制区；不同品种有不同方向、起点、跑跳／游动节奏。连续点另一只会取消上一场，旋转屏幕会安全结束并恢复原神兽。表演不自动打开弹窗，可主动点「查看进化」。减少动态效果设置下不做全园位移。

## 验证

数据测试覆盖 50 个唯一品种、300 组造型／动作定义、19 位唯一分配、原名册及组别保留、李冠德首次配置、换兽后刷新保持、奖励记录不变和六阶门槛边界。

可重复执行：`node scripts/test-pet-evolution.cjs`；构建：`node build.cjs`。

隔离浏览器测试不连接正式云端：390px 手机版无横向溢出，52px 关闭按钮，3 秒表演结束清理，未来预览不变更奖励，管理员确认交换后仍有 19 种不同伙伴。
