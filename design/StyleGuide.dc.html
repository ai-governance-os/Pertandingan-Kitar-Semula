镜头规则
Camera · the thing to fix first
✕ 取消 自动绕圈（现在每帧 camAngle += dt*0.1）
✕ 取消 学生一进来画面就在转 —— 会晕，也看不清自己的神兽
✓ 改成 固定构图：镜头停在一个精心取的角度
✓ 加入 极缓慢呼吸式漂移：±3° / 20 秒，几乎察觉不到
✓ 保留 手指拖动才转，放手后 4 秒缓缓回到构图
camera: fov 40 · position (cos(0.7)*34, 26, sin(0.7)*34) · lookAt(0, 1.5, 0)
drift: angle = base + sin(t * 0.05) * 0.05 // ±3°, 20s cycle
userDrag → autoDrift = false · 4s idle → ease back over 2.5s

打光与材质
Lighting & material
三盏灯就够：半球光 0.42（天蓝 ↔ 草绿）、主平行光 0.78（暖白 #FFF2D0，低角度 25°）、补光 0.18（冷色，从镜头反侧）。
不要过曝：总强度别超过 1.3，否则颜色会全部冲白（这是第一版最大的问题）。
材质走「有质感的卡通」：MeshStandard，roughness 0.85、metalness 0，配轻微环境光遮蔽；不要纯平的 cel 色块，也不要塑料反光。
雾：从 85 到 150 单位，颜色取地平线色 —— 远景变淡才有空气感。
阴影：1024 贴图、PCFSoft、bias −0.0006；只有神兽和树投影。
神兽系统
One per student, never repeated
每人一只，全校不重复：由学生 ID 稳定分配，换手机、换电脑都是同一只。图鉴目前 12 只，全校 19 人还要再画 7 只。
三件事让它们看起来不一样：① 剪影（角 / 翼 / 尾 / 甲）② 灵光颜色（每只专属）③ 待机动作（麒麟踏步、凤凰理羽、灵龟缩头）。
进化只加不换：同一只神兽越大越华丽 —— 角变长、尾焰变多、灵光变亮，传说阶段脚下浮起光环。不要换成另一种生物。
饿了：灵光变灰、动作变慢、坐下不走；成长值不减，拿到新星星立刻恢复。
性能预算
Budget for school phones
三角形 ≤ 120k · 绘制调用 ≤ 300 · JS 记忆体 ≤ 60 MB
神兽用同一套骨架，靠配件和颜色区分 —— 19 只不能各自一份模型。
Three.js 只在进宠物页才载入，其他页面不受影响（现在已经是这样，保持）。
离开页面要销毁：几何体、材质、renderer 全部 dispose（低配手机会当掉就是死在这一步）。
跑不动的手机：自动退回 📋 列表版，不要硬撑。
