云同步设置指南

Panduan Sediakan Supabase · Cloud Sync Setup
⏱ 大约 5 分钟 · ~5 minit
1

建立 Supabase 项目

Buat projek Supabase
🔗 supabase.com/dashboard
  • 登入你的 Supabase 账号
  • 点选你的 organization（比如 "Keane Teow"）
  • 右上角点 "New Project"（绿色按钮）
2

填项目资料

Isi maklumat projek
字段 · Field填什么 · Nilai
Project Nameeco-warrior-belemang
Database Password点 Generate 自动生成 → 复制保存

→ 点 "Create new project" → 等约 2 分钟

💾密码保存好就行 —— app 用不到，是 Supabase 自己保管。
3

建立数据表

Cipta jadual pangkalan data

项目跑好后：左边栏 "SQL Editor" → "New query"

把下面整段 SQL 贴进去 → 点右下 "Run"：

-- 建一张表来存所有数据 create table app_state ( id text primary key, data jsonb, updated_at timestamptz default now() ); insert into app_state (id, data) values ('main', '{}'::jsonb); -- 开放读写（app 自己管理登入） alter table app_state enable row level security; create policy "allow_all" on app_state for all using (true) with check (true); -- 开启实时推送 alter publication supabase_realtime add table app_state;
✅跑成功会看到 "Success. No rows returned" · Berjaya
4

拿 API 配置

Dapatkan API config
  • 左下角齿轮 ⚙️ "Project Settings"
  • 左边二级菜单 → "API"
  • 复制两个值：
    Project URLhttps://xxxxx.supabase.co
    anon public key一长串 eyJhbGciOi...
⚠️只要 anon public！不要拿 service_role（那是管理员密钥，不能放前端）· Hanya anon public, JANGAN service_role
